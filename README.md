# Hugo Vieira — Portfólio

Portfólio profissional em HTML/CSS/JS puro, sem dependências externas.

## 📁 Estrutura

```
portfolio-hugo/
│
├── index.html              # Página principal
│
├── css/
│   ├── reset.css           # Reset de estilos padrão do browser
│   ├── variables.css       # Variáveis CSS (cores, fontes, espaçamentos)
│   ├── base.css            # Estilos globais do body e seleção
│   ├── nav.css             # Navbar fixa com efeito scroll
│   ├── hero.css            # Seção hero (tela inicial)
│   ├── sections.css        # Estilos compartilhados entre seções
│   ├── sobre.css           # Seção "Sobre Mim"
│   ├── skills.css          # Seção "Habilidades"
│   ├── contato.css         # Seção "Contato"
│   ├── footer.css          # Rodapé
│   ├── animations.css      # Keyframes e classe .reveal
│   └── responsive.css      # Media queries (tablet e mobile)
│
├── js/
│   ├── reveal.js           # Animação de scroll (IntersectionObserver)
│   └── nav.js              # Comportamento da navbar (scroll + menu mobile)
│
└── assets/                 # Pasta para imagens e ícones locais (vazia)
```

## 🚀 Como usar

Abra o arquivo `index.html` diretamente no browser — não precisa de servidor.

## 🎨 Personalização

Edite `css/variables.css` para mudar cores, fontes e espaçamentos globais sem
tocar em nenhum outro arquivo.
